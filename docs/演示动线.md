# 演示动线

> 用一台 iPhone 和一台墨水屏 Rom，约 **6 分钟**演完「扫码租 → 开机激活 → 到期提醒 → 续租或归还 → 订单完成」。
> 全程离线，没有真实登录、支付和物流。

---

## 演示前准备

| 准备 | 怎么做 |
|---|---|
| iPhone | 已装「XEO 租赁」，通知权限已允许。上一场演示留下的数据先清掉：**长按首页左上角 XEO 标志** → 演示工具 → 清空全部数据 |
| 墨水屏 Rom | 浏览器打开 `XEO-Rom-激活演示.html`。若停在「Rom 已就绪」首页，点右上角「演示」→ 重置演示 |
| 入口二维码 | 打印 `租赁入口二维码.html`，或直接显示在另一块屏幕上 |
| 现场 | 两台设备都充好电；墨水屏调到合适亮度；残影明显时先做一次全刷 |

---

## 第一幕 · 租（iPhone，约 2 分钟）

| # | 操作 | 讲什么 |
|---|---|---|
| 1 | 用 iPhone **系统相机**扫入口二维码 → 点「在 XEO 租赁中打开」 | 在影院看到柜机，扫码就能开始租 |
| 2 | 登录：手机号 + 任意 6 位验证码（或点 Apple 登录） | 正式版会对接微信 / XEO 账号 |
| 3 | 面罩：选尺码 | 适配要走在领取之前 |
| 4 | 绑带：对准前置摄像头**测头围**，可 ±1 cm 微调 | 不用尺子，手机就能量 |
| 5 | 镜片：填左右眼近视度数 | **只支持近视、不支持散光**，界面上写明 |
| 6 | 耳机：自带或租用 → 确认配件组合 | |
| 7 | 租期选 **3 天** → 确认订单 → 立即支付 → 二次确认点**取消** | 付款可以先放一放 |
| 8 | 进入待支付倒计时（10 分钟）→ 返回「我的订单」，找到这笔 → 继续支付 → **确定** | 10 分钟内随时回来付；超时订单自动关闭 |
| 9 | 订单变为「租赁中」 | 实际是在柜机取货后开始计时；Demo 简化为付款即开始 |

> 想演示「超时关闭」：在第 7 步取消后，演示工具 →「待支付订单剩 30 秒」，等它关闭。

---

## 第二幕 · 用（墨水屏 + iPhone，约 2 分钟）

| # | 操作 | 讲什么 |
|---|---|---|
| 10 | 墨水屏：欢迎 → **开始设置** | 开箱后第一次开机 |
| 11 | 连接网络：选 XEO_Cinema → 连接 → 下一步 | （演示界面，不真联网） |
| 12 | **扫码激活**：iPhone 首页点「扫一扫」，扫墨水屏上的二维码 → 手机提示「Rom 已激活」→ 墨水屏点「我已完成激活」 | 设备和租赁账号绑在一起 |
| 13 | 连接音频设备：选 **XEO 202 蓝牙音箱**（或耳机）→ 下一步 | XEO 自家音箱，蓝牙 5.4、支持 LDAC |
| 14 | 了解 XEO Pod（可选）→ 继续 | 半封闭 20 面体、9.2.4 沉浸声场、触觉反馈 |
| 15 | 连接并佩戴 BIG → 完成设置 → **开始观影** | 再次开机直接进入，不用重新设置 |

## 第三幕 · 还（约 2 分钟）

| # | 操作 | 讲什么 |
|---|---|---|
| 16 | iPhone 演示工具 →「租期剩 20 小时（即将到期）」→「3 秒后发送租期提醒通知」→ 回到桌面等通知 | 剩 1 天以内才提醒，不打扰观影 |
| 17 | 墨水屏「演示」→ **触发「租期即将到期」** → 去续租 → 显示二维码 | Rom 上同样会提醒 |
| 18 | iPhone「扫一扫」扫墨水屏二维码 → 进入续租 / 归还页 | 两块屏，同一个入口 |
| 19a | **续租**：选时长 → 支付 → 到期时间顺延 | 续租后 Rom 不用重新激活 |
| 19b | **或归还**：选「上门取件」（填地址 + 时间段）或「影院柜机」（选影院） | 两种还法 |
| 20 | 用订单页里的演示按钮一步步推进 → **订单完成** | 快递：运输中 → 核验中 → 完成；柜机：待核验 → 完成 |

> 想演示逾期：iPhone 演示工具「已逾期 5 小时」；墨水屏「演示」→ 触发「已逾期」，屏上显示逾期时长和续费二维码，只能「关闭，继续使用」。

## 演示结束后

- iPhone：演示工具 → **恢复真实时间**；需要的话 → 清空全部数据。
- 墨水屏：「演示」→ 重置演示。

## 现场常见问题

| 现象 | 处理 |
|---|---|
| 相机扫入口码没有弹出「在 XEO 租赁中打开」 | 确认装的是本 app；或直接在 app 里点「扫一扫」 |
| 没收到提醒通知 | 设置 → 通知 → XEO 租赁，确认已允许；通知要回到桌面或锁屏才看得到 |
| 墨水屏上的二维码扫不出来 | 手机离屏幕 20–30 cm，避开反光；必要时先全刷一次清残影 |
| app 打不开，提示不受信任的开发者 | 设置 → 通用 → VPN 与设备管理 → 信任开发者证书（个人团队签名每 7 天要重新安装一次） |
