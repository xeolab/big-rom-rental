# PRD-Rental-EPIC-000 · BIG + Rom 租赁体验 Demo · 产品总览

> **一句话**：用一台 iPhone 和一台墨水屏 Rom，把「在影院扫码租 → 开箱激活 → 到期续租或归还 → 订单完成」
> 这条租赁体验完整演示出来。没有后端、没有真实支付，重点是**流程走得通、看得懂、好看**。
>
> **依据**：内部方案《Big + Rom IMAX 租赁用户体验流程》（第一阶段讨论稿）+ 负责人 2026-10-21 口述与审核答复。
> **状态**：开发中（iOS 待 Xcode 安装后真机验证）。活文档，需求变了就地改。

---

## 1. 背景与目标

BIG + Rom 计划在影院放自助租赁柜机。原方案把体验拆成「体验 → 租 → 用 → 还」四段。
本 Demo 做其中**手机端的「租」与「还」**，以及**墨水屏 Rom 的「首次激活」和「到期提醒」**，用于内部评审与对外演示。

正式产品可能是微信小程序或 XEO 自有 App；**Demo 先做 iOS app**。

## 2. 用户与场景

- **演示者**拿着 iPhone 扫一张打印的二维码（代替柜机屏），在手机上走完租赁下单；
- 拿起墨水屏 Rom，走一遍开机激活（激活码用同一个 iOS app 扫）；
- 用「演示工具」把时间快进到「即将到期」「已逾期」，演示两端的提醒，再演示续租或归还直到订单完成。

## 3. 功能需求

### 3.1 iOS app · 租

| # | 需求 |
|---|---|
| R1 | **入口**：iPhone 系统相机扫纸面二维码直接打开 app（URL Scheme）；app 内也有「扫一扫」。 |
| R2 | **登录**：未登录先登录。提供「手机号 + 验证码」与「Apple 登录」两种方式，**均为占位**，不调用真实服务。 |
| R3 | **配件适配**，依次：面罩（S / M / L，可按面部扫描推荐）→ 绑带（**用前置摄像头真实测量头围**，结果可 ±1 cm 微调；设备不支持时手动填写）→ 镜片（手动填写左右眼近视度数，**只能填非负整数**，并明确写出**不支持散光**）→ 耳机（自带 / 租用）→ 确认配件组合。 |
| R4 | **租期**：1 天 / 3 天 / 7 天，价格为示意价。 |
| R5 | **假支付**：点「立即支付」→ 二次确认。确定 = 支付成功，订单进入租赁中；取消 = 进入**待支付倒计时（10 分钟）**页面。 |
| R6 | **订单列表**：能找到待支付订单；倒计时未结束可继续支付，结束则订单**已关闭**。 |

### 3.2 iOS app · 还

| # | 需求 |
|---|---|
| H1 | **到期提醒**：临近到期弹系统通知，可「续租」或「稍后提醒」；app 内显示即将到期 / 已逾期提示。 |
| H2 | **续租**：选新的租期 + 假支付，到期时间顺延。 |
| H3 | **归还方式**：预约快递上门取件（地址 + 时间段），或选择影院柜机自行归还（示意影院列表）。 |
| H4 | **归还进度**：柜机归还 → 待核验 → 订单完成；快递 → 已预约 → 运输中 → 核验中 → 订单完成。**由演示按钮手动推进**。 |
| H5 | 扫墨水屏上的**激活码**：把 Rom 关联到当前租赁订单；扫**续租码**：打开该订单的续租 / 归还页。 |

### 3.3 墨水屏 Rom 演示

| # | 需求 |
|---|---|
| E1 | **首次启动与激活**（原方案 §3.2，完整做）：欢迎 → 连接网络（**演示界面**，不真联网）→ 扫码激活（墨水屏显示二维码，用 iOS app 扫）→ 连接音频设备 → 了解 XEO Pod（可跳过）→ 连接并佩戴 BIG → 开始观影。 |
| E2 | **再次使用**：已激活过则直接进入已激活首页，不重复设置。 |
| E3 | **即将到期弹窗**：显示剩余天数与到期时间；「稍后提醒」关闭，「去续租」显示静态二维码，用 iOS app 扫码续租或归还。 |
| E4 | **已逾期弹窗**：显示逾期时长和续租 / 付费二维码，只提供「关闭，继续使用」按钮。 |
| E5 | 做成单文件网页，拷到墨水屏安卓机用浏览器打开即可；遵守墨水屏 UX 硬约束（无动画、高对比、触控目标够大）。 |

### 3.4 通用

- **视觉**：流程参照原方案，**视觉按 XEO 品牌规范重做**（白底黑字、XEO 紫点缀、大量留白），不沿用原方案示意图的风格。
- **演示工具**：时间快进、立即触发提醒、重置数据——方便现场在几分钟内演完全程。

## 4. 验收标准

1. 打印入口二维码，iPhone 相机扫码能直接打开 app 并进入租赁流程。
2. 从登录走到「订单租赁中」全程无卡点；取消支付后能在订单列表找到并继续支付；10 分钟后该订单显示已关闭（可用演示工具缩短）。
3. 头围测量在支持面容 ID 的 iPhone 上能给出合理估算值（真机核对，偏差可接受范围待定）；度数框无法输入负数和小数。
4. 墨水屏端从欢迎走到开始观影；激活码、续租码能被 iOS app 正确识别并跳到对应页面。
5. 用演示工具触发「即将到期 / 已逾期」，两端提醒都能演示；续租后到期时间顺延；两种归还方式都能推进到订单完成。
6. 整体观感符合 XEO 品牌规范（负责人目视验收）。

## 5. 非目标

- 柜机体验装置、柜机出货与领取（原方案 §2.5）、BIG 连接与初始化（§3.3）、观影内容（§3.4–3.5）。
- 真实登录、真实支付、押金 / 信用分免押、短信、物流对接、后端服务。
- 预存影片卡带（原方案 §2.4 可选项）。

## 6. 开放问题

- 头围测量的可接受误差、面罩尺码与头围 / 脸宽的对应关系（目前为示意规则）。
- 正式产品是微信小程序还是 XEO App（影响后续是否沿用本 Demo 的交互）。
