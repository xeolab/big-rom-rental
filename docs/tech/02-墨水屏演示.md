# 02 · 墨水屏演示（Rom 首次激活 + 租期提醒）

> **一句话**：`eink/` 构建出两个**单文件、离线**的 HTML——墨水屏上跑的「Rom 首次启动与激活」演示，
> 以及打印用的「租赁入口二维码」。不联网、不调后端；与 iOS 端唯一的接口是二维码里的 URL（见 [01](01-架构与双端契约.md) §2）。

---

## 1. 结构与构建

```
eink/
  build.mjs                     # Node 22，无依赖：src + vendor + brand/logo_black.svg 内联成单文件
  src/shell.html · app.css · app.js   # 激活演示
  src/print.html                # 打印页（自带极简脚本）
  vendor/qrcode-generator/      # Kazuhiko Arase qrcode-generator 1.4.4（MIT，原样，版权头在文件内）
  test/cdp.mjs                  # headless Chrome 驱动（复用自 xeo-big-movie-box games/test）
  test/flow.json · print.json · other-wifi.json   # 全流程用例
  test/decode_qr.py             # OpenCV 独立解码截图里的二维码，逐字比对契约
  dist/XEO-Rom-激活演示.html     # ← 拷到墨水屏机
  dist/租赁入口二维码.html        # ← 用电脑浏览器打开、打印 A4
```

`node eink/build.mjs` 重新生成 `dist/`。**不许**引入外链 / fetch / import / 相对资源（理由同 Game Rom：
Android 从文件管理器打开本地 HTML 走 `content://`，相对子资源会失效）。

## 2. 页面

| # | 页 | 要点 |
|---|---|---|
| 1 | 欢迎 | 简短欢迎词 + 线稿插画 |
| 2 | 连接网络 | **演示界面**：Wi-Fi 列表（XEO_Cinema / Cinema_WiFi / XEO_Guest / 其他网络…），选中加密网络出现密码框（可留空），「连接」后显示「已连接」；未连接时「下一步」禁用 |
| 3 | 扫码激活 | `xeorental://activate?device=ROM-DEMO-0001`；墨水屏无从得知手机是否扫成功，由用户点「我已完成激活」继续 |
| 4 | 连接音频设备 | 蓝牙 / 有线 / 暂不使用（单选，必选） |
| 5 | 了解 XEO Pod（可选） | 跳过 → 第 6 步；了解更多 → 一页简介 → 继续 |
| 6 | 连接并佩戴 BIG | USB-C 连接示意 + 三步说明 |
| — | 设置完成 → 已就绪首页 | 激活状态写入 localStorage（读写都包 try/catch）；**再次打开直接进首页**（原方案 §3.6 再次使用） |

**演示面板**（右上角虚线框「演示」，正式产品中没有）：

- **租期即将到期**：剩余 3 天 + 到期时间；「稍后提醒」关闭，「去续租」→ 续租二维码 `xeorental://renew?device=ROM-DEMO-0001` + 关闭。
- **已逾期**：逾期时长（演示固定 5 小时）+ 到期时间 + 同一续租二维码，**只有「关闭，继续使用」一个按钮**（负责人定）。
- 全屏显示、重置演示（清激活状态，回到欢迎页）。

## 3. 墨水屏适配

- 无动画 / 无过渡 / 无平滑滚动；每次操作整屏重绘一次。
- 白底黑字，XEO Purple `#6638B6` 只用于主按钮、当前步骤与左侧品牌竖条；**状态一律靠形状**（选中 = 加粗边框 + 实心 ✓，当前步骤 = 外框描边），不靠颜色。
- 弹窗是**整屏纯白**，不用半透明遮罩（灰色在墨水屏上会抖动成噪点）。
- 触控目标全部 ≥48px（用例里自动检查）。
- 品牌标识直接内联 `brand/logo_black.svg`，只去掉 XML 头并把 viewBox 收到标识本体（四周留安全边），不重绘。

## 4. 二维码

- 本地生成（qrcode-generator，纠错等级 M），**每个模块是整数像素**、关闭平滑 ⇒ 边缘锐利，墨水屏上不出灰边。
- 尺寸：屏幕可用宽度、高度 42% 二者取小，上限 400px；四周 4 模块静区 + 黑框。
- **校验**：headless Chrome 截图（手机 412×824、平板 768×1024，DPR 2）+ 打印页截图，用 OpenCV `QRCodeDetector`
  独立解码，原尺寸与 1/2 缩放都必须**逐字等于**契约字符串（脚本见本篇末「怎么测」）。

## 5. 上机

```bash
adb push eink/dist/XEO-Rom-激活演示.html /sdcard/Download/
```

在墨水屏机上用浏览器打开（文件管理器点开，或地址栏 `file:///sdcard/Download/XEO-Rom-激活演示.html`），
建议在演示面板里点「全屏显示」。入口二维码：电脑浏览器打开 `eink/dist/租赁入口二维码.html` → 打印（A4，二维码约 11 cm）。

## 6. 怎么测

```bash
node eink/build.mjs
node eink/test/cdp.mjs "file://$PWD/eink/dist/XEO-Rom-激活演示.html" eink/test/flow.json /tmp/eink-shots/phone 412x824
node eink/test/cdp.mjs "file://$PWD/eink/dist/租赁入口二维码.html" eink/test/print.json /tmp/eink-shots/print 794x1123
```

`flow.json` 走完整流程（欢迎 → … → 完成 → 刷新进首页 → 两种提醒 → 重置），最后一项输出小于 48px 的按钮（应为空）；
`logs` 应为空。再跑平板尺寸（`768x1024` 输出到 `/tmp/eink-shots/tablet`）后，独立解码核对：
`uv run --with opencv-python-headless python3 -I eink/test/decode_qr.py /tmp/eink-shots`（7 张全部 `OK` 才算过）。

## 7. 已知限制

- Wi-Fi、蓝牙耳机都是演示界面，不调系统能力（需要的话得做原生 app）。
- 激活与续租是否成功，墨水屏端无从得知（无后端），由用户手动点继续 / 关闭。
- 到期时间是「今天 + 3 天 24:00」的示意值，与手机端订单不同步。
- localStorage 只在同一浏览器、同一打开方式下保留；从文件管理器（`content://`）与地址栏（`file://`）打开可能被视为不同来源。
- **未上墨水屏真机**：刷新观感、二维码在 Kaleido 3 屏上的实际可扫距离待负责人验。
