# 01 · 架构与双端契约

> **一句话**：两个互不联网的演示端——**iOS app**（`ios/`，租与还的全流程）和**墨水屏演示**（`eink/`，Rom 首次激活 + 租期提醒）——
> 之间唯一的「接口」是**静态二维码里的 URL**。没有后端，所有数据都在各自本地。
>
> 需求见 [`../prd/PRD-Rental-EPIC-000-产品总览.md`](../prd/PRD-Rental-EPIC-000-产品总览.md)。

---

## 1. 组成

```
纸面二维码 ──(iPhone 系统相机)──▶ iOS app：登录 → 适配 → 租期 → 假支付 → 订单 / 提醒 / 续租 / 归还
                                     ▲
墨水屏演示（安卓浏览器打开单文件 HTML）  │ app 内「扫一扫」
  首次激活：…→ 显示激活二维码 ───────────┤
  租期提醒 / 逾期：显示续租二维码 ────────┘
```

- **iOS app**：SwiftUI，本地持久化，无网络请求。所有「支付 / 登录 / 物流」都是演示用占位。
- **墨水屏演示**：单个自包含 HTML（理由同 xeo-big-movie-box 的 Game Rom：Android 从文件管理器打开走 `content://`，相对资源会失效），
  跑在墨水屏安卓机的浏览器里。遵守墨水屏 UX 硬约束（无动画、高对比、触控 ≥48dp）。

## 2. 二维码契约（两端必须一致，改动先改这里）

URL Scheme：**`xeorental`**（iOS 在 `Info.plist` 注册；系统相机扫码会提示「在 XEO 租赁中打开」）。

| 二维码 | 在哪显示 | 内容 | iOS 收到后 |
|---|---|---|---|
| **租赁入口** | 打印在白纸上（模拟柜机屏） | `xeorental://rent?cabinet=XEO-IMAX-DEMO-01` | 未登录 → 登录；已登录 → 进入配件适配，开始新订单 |
| **设备激活** | 墨水屏首次激活第 3 步 | `xeorental://activate?device=ROM-DEMO-0001` | 把该设备绑定到当前「租赁中」订单，显示「Rom 已激活」；没有租赁中订单 → 提示先完成租赁 |
| **续租 / 逾期处理** | 墨水屏到期提醒、逾期弹窗 | `xeorental://renew?device=ROM-DEMO-0001` | 打开该设备所属订单的「续租 / 归还」页 |

- 参数一律只读、可缺省；未知 host 或参数 → app 打开首页并提示「无法识别的二维码」。
- 墨水屏端**不知道**手机端是否扫码成功（没有后端）：扫码后由用户在墨水屏上点「我已完成激活 / 关闭」继续。

## 3. iOS 订单状态机

```
            立即支付 → 二次确认「确定」
pendingPayment ──────────────────────────▶ renting ──(到期前 ≤ 阈值)──▶ [即将到期]（派生，不是存储状态）
  │  二次确认「取消」→ 留在 pendingPayment            │            └──(过了到期时间)──▶ [已逾期]（派生）
  │  10 分钟内可在订单列表继续支付                       │ 续租：选时长 + 假支付 → endsAt 顺延
  └─ 超时 ──▶ closed                                    │ 归还：
                                                        ├─ 上门取件：returnScheduled(courier) → inTransit → verifying → completed
                                                        └─ 柜机归还：returnScheduled(cabinet) → verifying → completed
```

- **支付倒计时 10 分钟**（负责人定）。演示时可在「演示工具」里把剩余时间拨到 30 秒。
- **租期从支付成功开始计**（原方案是从柜机取货开始；柜机出货不在本 Demo 范围）。
- 归还后的状态推进由**演示按钮手动推进**（负责人定），不做定时自动推进。
- 「即将到期」阈值：剩余 ≤ 3 天（与原方案示意一致）；演示工具可把当前时间快进到「剩 2 天」「已逾期 5 小时」。

## 4. 演示数据（两端共用的示意值）

| 项 | 值 |
|---|---|
| 柜机 / 设备 | `XEO-IMAX-DEMO-01` / `ROM-DEMO-0001` |
| 租期与示意价 | 1 天 ¥99 · 3 天 ¥249 · 7 天 ¥449（标注「示意价」，一处配置） |

| 上门取件 | 示意时间段（今天 / 明天 × 上午 / 下午） |
